سبزنت - نسخه پنل‌های رنگی Telegram Bot API 9.4+

فایل اصلی: SabzNet_admin.py

متغیرهای Railway:
BOT_TOKEN=توکن جدید ربات
ADMIN_IDS=9158813748
OWNER_CHAT_ID=9158813748
DATABASE_PATH=/data/sales.db

یک Volume در Railway بسازید و Mount Path را /data قرار دهید.

رنگ دکمه‌ها (در کلاینت‌های به‌روز تلگرام):
- پنل اصلی خدمات: آبی (primary) با همان چیدمان و ترتیب خدمات.
- پنل مدیریت و زیرمنوهای ویرایش: سبز (success).
- حذف محصول/کارت و رد پرداخت: قرمز (danger).
- تأیید پرداخت: سبز.

منوی رسمی بات سه دستور دارد:
/start شروع مجدد
/myid پروفایل کاربر
/admin پنل مدیریت (فقط مدیر)

امکانات مدیریتی موجود در سورس:
مدیریت محصولات، افزودن محصول، تغییر قیمت/نام/آیکون/دسته‌بندی/استیکر، فعال/غیرفعال و حذف؛ پیام همگانی؛ آمار و فهرست کاربران؛ تنظیم و حذف شماره کارت و نام گیرنده؛ کد تخفیف؛ بکاپ و ریستور دیتابیس؛ ویرایش متن خوش‌آمدگویی، پشتیبانی، توضیحات کانفیگ، راهنما، سرویس تست و متن کانفیگ ارسالی.

توکن داخل سورس نیست و فقط از BOT_TOKEN خوانده می‌شود.
برای نمایش رنگ‌ها، برنامه تلگرام کاربران باید نسخه‌ای داشته باشد که استایل دکمه‌های Bot API 9.4 را پشتیبانی کند؛ در کلاینت قدیمی ممکن است دکمه‌ها با رنگ پیش‌فرض نمایش داده شوند.
ایموجی‌های معمولی قابل رنگ‌آمیزی جداگانه نیستند؛ رنگ آبی/سبز روی پس‌زمینه دکمه اعمال می‌شود.
