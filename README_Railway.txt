سبزنت - منوی خدمات به‌صورت کیبورد اصلی تلگرام

در این نسخه پس از ارسال /start، متن خوش‌آمدگویی همراه با کیبورد اصلی خدمات ارسال می‌شود.
دکمه‌های خدمات از نوع ReplyKeyboard هستند و در پایین صفحه چت، بالای کادر پیام، به‌صورت دائمی نمایش داده می‌شوند.
چیدمان:
- سلف و تبچی در یک ردیف تمام‌عرض
- شماره مجازی و گیفت استارزی
- کانفیگ اختصاصی و پرمیوم
- استارز و پشتیبانی

نکته: رنگ دکمه‌های ReplyKeyboard توسط کلاینت تلگرام و تم کاربر کنترل می‌شود و Bot API امکان تعیین رنگ مستقل برای آن‌ها ندارد.

فایل اجرا: SabzNet_admin.py
Procfile: worker: python SabzNet_admin.py
