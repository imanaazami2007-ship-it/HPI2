زئوس شاپ - کیبورد خدمات و دکمه‌های شیشه‌ای رنگی

پس از /start متن خوش‌آمدگویی همراه با کیبورد اصلی خدمات نمایش داده می‌شود.
کیبورد اصلی از نوع ReplyKeyboard است و چیدمان آن:
- سلف و تبچی در یک ردیف تمام‌عرض
- شماره مجازی و گیفت استارزی
- کانفیگ اختصاصی و پرمیوم
- استارز و پشتیبانی

رنگ‌بندی دکمه‌های شیشه‌ای (Inline Keyboard):
- انتخاب محصولات، پلن‌ها و دکمه‌های پشتیبانی مشتریان: آبی (primary)
- دکمه‌های پنل مدیریت: سبز (success)
- حذف/رد/عملیات مخرب: قرمز (danger)

نکته: رنگ ReplyKeyboard (کیبورد اصلی پایین صفحه) را تلگرام/تم کاربر تعیین می‌کند؛ رنگ‌آمیزی بالا مربوط به دکمه‌های شیشه‌ای زیر پیام‌هاست. نمایش رنگ‌های Inline Keyboard به نسخه‌ای از تلگرام نیاز دارد که Bot API 9.4 را پشتیبانی کند.
